# OrbitAlert

## Descrição

O OrbitAlert é uma plataforma web desenvolvida para auxiliar no monitoramento e na conscientização sobre eventos climáticos extremos no Brasil.

A solução transforma informações ambientais complexas em dados acessíveis e fáceis de compreender, permitindo que usuários acompanhem riscos relacionados a chuvas intensas, secas, queimadas e enchentes de forma simples e intuitiva.

O projeto foi desenvolvido para a Global Solution FIAP 2026, dentro da temática de Economia Espacial e Monitoramento Ambiental, utilizando conceitos inspirados em satélites meteorológicos, observação terrestre e sistemas de alerta.

---

# Objetivo

O OrbitAlert tem como objetivo:

- Facilitar o acesso a informações sobre riscos climáticos.
- Promover a conscientização ambiental.
- Simular possíveis impactos de eventos climáticos extremos.
- Apoiar a prevenção de desastres naturais.
- Demonstrar como tecnologias inspiradas na economia espacial podem contribuir para a sociedade.

---

# Problema Abordado

O Brasil enfrenta constantemente problemas relacionados a eventos climáticos extremos, como:

- Enchentes
- Secas prolongadas
- Queimadas
- Chuvas intensas
- Deslizamentos

Embora existam sistemas de monitoramento avançados, muitas informações são apresentadas de forma técnica e pouco acessível para a população.

O OrbitAlert busca reduzir essa barreira, apresentando os dados de forma visual, intuitiva e educativa.

---

# Motivação

A proposta surgiu da necessidade de aproximar tecnologias de monitoramento ambiental da população.

Inspirado em sistemas de observação terrestre e monitoramento via satélite, o projeto demonstra como informações climáticas podem ser transformadas em ferramentas úteis para conscientização, prevenção e tomada de decisão.
